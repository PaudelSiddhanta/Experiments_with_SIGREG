# BYOL + SIGReg

Controlled experiments investigating whether SIGReg can replace
BYOL's collapse-prevention machinery.

Initial experiments:
- BYOL baseline
- BYOL + SIGReg
- BYOL without EMA + SIGReg
- Fully symmetric invariance + SIGReg
- Symmetric invariance without regularization

Initial dataset: CIFAR-10
Initial backbone: ResNet-18
